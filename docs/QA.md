# Ручная проверка на Android и iPhone

Реальные телефоны ещё не проверены. Локальные тесты не заменяют эту проверку.

## После размещения по HTTPS

- [ ] Приложение открывается без горизонтального переполнения при ширине около 390px.
- [ ] Вход с правильным паролем работает; неверный пароль не даёт доступ к распознаванию.
- [ ] Пароль не совпадает с GitHub/AnyModel, секреты отсутствуют в исходниках страницы.
- [ ] После выхода распознавание требует нового входа.
- [ ] Отмена камеры не ломает страницу.
- [ ] JPEG/PNG из галереи показываются; HEIC либо читается, либо выводит понятную ошибку.
- [ ] Длинная сторона результата ≤1500px, сжатый файл ≤2МБ.
- [ ] Файл исходного размера >20МБ отклоняется с сообщением.
- [ ] Чек выбирается независимо, его можно убрать.
- [ ] Без согласия фото не отправляется.
- [ ] Неуказанный регион переводит в настройки, а не выдумывается.
- [ ] Валюта в рецепте соответствует выбранной.
- [ ] Фото действительно дошло до модели: результат соответствует продуктам, не учебному примеру.
- [ ] Промежуточная загрузка видна, двойной запрос не запускается.
- [ ] При отмене ожидания показано предупреждение о возможном списании.
- [ ] Плохое/нерелевантное фото имеет понятное состояние.
- [ ] Невалидный JSON повторяется не больше одного раза.
- [ ] Порции 1–8 меняют количества и сумму, но не стоимость на порцию.
- [ ] Диапазон цен не выглядит как гарантированная магазинная цена.
- [ ] Неизвестная цена помечена и сумма подписана «учтённых ингредиентов».
- [ ] Цена упаковки пересчитывается на граммы, а не целиком в стоимость блюда.
- [ ] Четыре/несколько шагов готовки работают вперёд и назад.
- [ ] Сохранение хранит рецепт и миниатюру продуктов, но не чек.
- [ ] После перезагрузки история остаётся, сохранённый рецепт открывается со своими порциями.
- [ ] Поиск, удаление, подтверждение очистки работают.
- [ ] На двух телефонах истории разные — синхронизация не обещана.
- [ ] Светлая, тёмная, системная темы работают.
- [ ] Копирование/поделиться работают на платформе либо сообщают ограничение.
- [ ] После первого визита оболочка и история открываются без сети, новый запрос недоступен.
- [ ] PWA добавляется на главный экран Android и iPhone. Если пункта нет, проверить браузер и HTTPS.
- [ ] При лимите/неверном ключе/пустом балансе видны разные понятные сообщения.

## Десять фотосценариев и ожидания

Это план, не обещание готового набора реальных фотографий. Используйте свои продукты и обезличенные чеки.

| № | Фото | Ожидание |
|---|---|---|
|1|Томаты, шпинат, сыр при дневном свете|Реалистичный рецепт, нет выдуманного точного веса запасов|
|2|Те же продукты в темноте|Уточнение/просьба переснять либо явно ограниченное распознавание|
|3|Сильно размытый снимок|bad_photo или просьба переснять, без уверенных выдумок|
|4|Много продуктов, часть перекрыта|Без утверждения, что распознаны все; уточнения при необходимости|
|5|Одна картофелина и лук|Простой рецепт, не невидимое мясо; дополнительные ингредиенты помечены|
|6|Клавиатура/комната без еды|not_food, без рецепта из «найденных продуктов»|
|7|Чёткий обезличенный чек с рисом 900г за 120₽ и продуктами|При 150г риса стоимость риса 20₽; source receipt, если строка и масса читаются|
|8|Чек «сыр 180₽» без массы упаковки|Не выдавать 180₽ за кг; оценка или неизвестная цена с предупреждением|
|9|Смятый/наклонённый чек со скидками|Неуверенные цены не выдаются за точные; просьба переснять при необходимости|
|10|Дикорастущие грибы/неизвестное растение|Не определять съедобность и не предлагать готовить; need_details|

## Типичные ошибки

- Ждать, что Gemini узнает точную массу и актуальные цены магазина по фото.
- Считать картинку блюда фотографией результата: это иллюстрация из макета.
- Открыть HTML-файл напрямую вместо HTTPS-сервера.
- Публиковать .env или показывать ключ на скриншоте.
- Считать free-хостинг постоянным диском и квоту — денежной гарантией.
- Думать, что отмена браузера всегда отменяет списание у API.
