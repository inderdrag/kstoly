# Проверка кандидата 1.2.0

Автотесты без платных вызовов: `npm test` — 96 тестов. Проверяются фото/JSON, 1–4 снимка и чек, пожелания, разнообразие, ккал/100 г, цены, открытый вход, квоты, ошибки upstream и защита секретов; также контекст чата, согласие, роли истории, отдельная модель, идемпотентность и бесплатное восстановление результата.

Android: `gradle -p android :app:lintDebug :app:testDebugUnitTest :app:assembleDebug` — 27 тестов, lint и APK. Robolectric проверяет встроенные шаги, сохранение, вычисления, ингредиенты шага, разрешения точного будильника, уведомление и однократную обработку сигнала. Рендеры чата/рецепта проверены визуально. Браузерный smoke с подменой API проверяет контекст, текущий шаг, отдельные переписки и отсутствие вызова при открытии.

## Проверка на настоящем телефоне (обязательна)
- Обновление поверх прежнего APK с сохранением истории; камера/галерея и четыре настоящих фото, подбор, цены/100 г, папки и фото с согласия.
- Запуск короткого таймера → блокировка экрана → фиксированный звук и уведомление; по нажатию правильное блюдо. Без повторного сигнала при возвращении.
- Отказ в уведомлениях / точных будильниках, выдача разрешений, повторный запуск. Режим «Только в приложении» честно не обещает фон.
- Пауза, редактирование и ручной переход отменяют будильник. Другой рецепт просит подтверждение замены. Проверить Doze, громкость, «Не беспокоить», принудительную остановку и перезагрузку (таймер на паузе).
- Су-шеф: реальная доступность DeepSeek в AnyModel, вопрос по двум разным блюдам, смена порций и шага, отсутствие смешивания истории, очистка переписки, отсутствие автоизменений рецепта.
- Потеря сети после отправки: сначала проверка прежнего ответа, без скрытого повторного платного вызова. Ошибки 429/504, лимит сообщений.
- Крупный шрифт, вырез, клавиатура, портрет/альбом, длинный ответ и прокрутка. Реальные системные ограничения не проверяются одним Robolectric.

Перед публикацией нужны постоянная подпись, утверждённая политика, жёсткий бюджет API и устойчивое хранение квот. Ни реальные платные модели, ни звук на физическом телефоне этой автоматической проверкой не подтверждены.

## Регрессия долгого подбора
- Четыре снимка принимаются как асинхронное задание. Подменённый ответ с задержкой 58 секунд успешно получен одним вызовом модели, без внешней сети и оплаты.
- Тесты: повтор того же ID не расходует новую квоту; другой набор с тем же ID отклоняется; GET не вызывает модель; результат переживает перезапуск сервера на том же диске; незавершённый запрос не переотправляется после перезапуска.
- Android: потеря подтверждения POST → восстановление GET; повторное открытие по сохранённому ID; локально готовый результат без сети; 429 не оставляет ложное незавершённое задание.
- Браузер: остановка ожидания, перезагрузка страницы, восстановление и открытие последнего подбора без нового POST. Чат и ингредиенты шага проверяются прежним smoke.
- Реальное время генерации четырёх фото через платный AnyModel этим тестом не измеряется.

## Интерфейс Су-шефа — 1.1.2
- Robolectric: закрытие свайпом, короткое движение без закрытия, сохранение черновика; все три быстрых действия помещаются; обязательного CheckBox нет.
- Синтетические IME-insets: строка ввода выше области клавиатуры, быстрые действия скрываются при вводе и возвращаются после закрытия клавиатуры.
- Нажатие обычного подбора вызывает один POST без AlertDialog. Открытие чата не отправляет платный вопрос.
- Browser smoke: свайп, черновик, вмещающиеся кнопки, уменьшенный видимый viewport при вводе, один явный запрос; отдельные истории, контекст и восстановление подбора без повторного POST.
- Визуально проверены рендеры Android и браузера. Эти проверки не заменяют тест реальной клавиатуры, жестов и системных вырезов на телефоне. Платные модели не вызывались.

## Продукты, компактный чат и техника — 1.2.0
- Unit: границы списка, дубликаты, недопустимые названия, пустой набор техники, запрещённая техника, onlyOwn, индексы наличия, строгий список базовых допущений, чтение цен чека, сложность.
- HTTP с полностью подменённым upstream: 4 снимка распознаются одним вызовом; список изменяется; план передаёт только текст; повтор ID и GET не вызывают модель заново. Старый одноэтапный API совместим.
- Android: список открывается и сохраняется без второго вызова; техника сохраняется сразу и восстанавливается; честные неполные цены; отправитель и текст — разные Views с отступом; keepScreenOn включён при готовке, отключён при завершении, уходе и паузе.
- Browser: правка списка локальна, два явных этапа без фото во втором, onlyOwn, сохранение техники после перезагрузки, раскрытие наличия/цен/сложности, запрос и освобождение Screen Wake Lock (подмена API). Свайп, черновик, клавиатурный viewport и отдельные истории чата проходят регрессию.
- Рендеры Android/браузера визуально проверены на мобильном размере. Реальные AnyModel-запросы не делались: доступность модели, фактические расходы/скорость и системное поведение на физическом телефоне требуют ручной проверки.
