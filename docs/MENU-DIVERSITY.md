# Разнообразный подбор — серверное обновление 0.8.1-menu

При большом и разнообразном наборе распознанных продуктов цель — 6–10 рецептов, ориентир 8. При ограниченном наборе допустимы 1–5 реальных вариантов: основные продукты не выдумываются ради количества.

В промпте приоритет отдан горячим блюдам, супам, гарнирам, завтракам и другим способам приготовления из видимых продуктов. Салатов допускается не больше двух в подборе из 6–10 и одного в подборе из 3–5. Валидатор проверяет категорию и характерные названия салатов; при нарушении используется прежняя единственная попытка исправления ответа. Нельзя гарантировать корректность классификации любой моделью, поэтому результат всё равно требует проверки пользователем.

Система, исходный запрос и исправление JSON используют общие правила SELECTION_RULES. Исправление больше не требует ровно трёх рецептов. Поле meal_type необязательно для старых рецептов, новые варианты запрашиваются с категорией. Горячие/основные варианты располагаются перед салатами. Ккал, цены, описания фото, прежние сохранения и API входа сохраняют совместимость.

Максимум recipes увеличен с 5 до 10, бюджет ответа — с 12000 до 18000 токенов. Большой ответ может занять больше времени и стоить больше по тарифу поставщика. Дневные лимиты запросов, тайм-аут 55 секунд, максимум две upstream-попытки, согласия и ключи не менялись. Нет скрытой серии запросов для добора количества.

Для применения достаточно успешного развёртывания последнего коммита на Render и нового подбора в приложении. APK пересобирать не требуется: клиент уже отображает весь массив recipes. Старый сохранённый подбор сам не перегенерируется. Проверка версии: GET /api/status, поле build = 0.8.1-menu.

Проверено: 29 целевых Node-тестов; локальный HTTP-сценарий входа, выдачи 8 рецептов, исправления ответа из одних салатов без сокращения до трёх, сохранения ккал, неизвестных цен и отказа без авторизации. В сценарии внешняя модель и неизменённый сервис изображений изолированы заглушками; платные запросы и реальные фото не использовались. Это не доказательство качества распознавания конкретного холодильника.
