# Разнообразный подбор

Цель для полного холодильника — 6–10 реальных блюд, ориентир 8. Для ограниченного набора допускается меньше. Нельзя выдумывать основные продукты ради количества.

Горячие блюда, супы, гарниры и завтраки имеют приоритет; салатов максимум два в большом подборе и один в наборе из 3–5 блюд. Категории и характерные названия проверяются валидатором. При ошибке допускается одна попытка исправления JSON с теми же правилами разнообразия.

Максимум ответа 24000 токенов; тайм-аут внешнего запроса 55 секунд. Большой подбор может стоить дороже, это не скрытая серия запросов за отдельными рецептами. Все шаги приходят вместе с подбором. Старые сохранения сами не перегенерируются.
