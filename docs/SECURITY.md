# Безопасность и деньги

Только личная тестовая версия с одним владельцем. Не открывать регистрацию и не раздавать пароль другим людям.

## Секреты

- API-ключ AnyModel только в ANYMODEL_API_KEY на сервере.
- APP_PASSWORD — отдельный пароль приложения (не пароль GitHub), от 16 символов.
- SESSION_SECRET — отдельная случайная строка от 32 символов.
- Не публиковать .env, скриншоты секретов, файлы резервных копий окружения.
- При утечке: отозвать ключ в AnyModel, создать новый, заменить секрет на хостинге и перезапустить приложение. Если утёк пароль приложения — заменить также SESSION_SECRET, это аннулирует все cookie.

## Лимиты

- 20 пользовательских запросов в день, 30 попыток поставщика; невалидный JSON может использовать две попытки. День по UTC.
- Один запрос нейросети одновременно в одном экземпляре.
- Таймаут поставщика 55 секунд на попытку, максимум две попытки; UI прекращает ждать через 120 секунд.
- До двух JPEG по 2МБ, размеры 16–1500 px по каждой стороне, HTTP JSON до 6МБ.
- Десять попыток входа за 15 минут на сетевой адрес. За прокси пользователи могут делить один адрес; для личного теста это консервативное ограничение, не полноценная защита от распределённых атак.
- Cookie 7 дней, HttpOnly, SameSite Strict; в production Secure и HTTPS обязательны.
- Отмена ожидания в браузере не гарантирует отмену у поставщика/возврат оплаты.
- SQLite хранит только дневные счётчики. На временном диске они теряются при потере файлов. Не обещать жёсткий денежный потолок. Лимит токенов ключа у AnyModel остаётся дополнительной мерой, его точную семантику проверить у сервиса.

## Данные

Код не пишет фото/промпты/ответы/ключи в журнал или на диск сервера. Изображения существуют в памяти на время запроса; сборка мусора не гарантирует немедленного физического стирания. Хостинг и поставщики имеют собственные технические журналы/политики. Режим Ghost Mode AnyModel, если включён, не отменяет передачу поставщику и не является гарантией отсутствия хранения у всех участников.

История и миниатюры фото продуктов локальные в браузере. На общем устройстве другие пользователи браузера могут их увидеть. Выход из аккаунта не очищает локальную историю автоматически — используйте «Очистить историю».

## Перед публичным доступом

Нужны проверка угроз/зависимостей, отдельные пользователи и устойчивая квота на каждого, база постоянного хранения, защита от злоупотреблений, мониторинг расходов без фото, окончательная политика и права на макет. Текущая версия к этому не готова.
