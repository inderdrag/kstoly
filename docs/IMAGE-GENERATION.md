# Фото блюда

В каждом рецепте есть явная кнопка генерации. Создание только после согласия; просмотр результата предшествует сохранению. Android сохраняет состояние задания, повторное нажатие получает прежний результат, если он доступен, а не создаёт случайную новую попытку. Отказ от фото не возвращает потраченную квоту.

Cloudflare используется только при настроенных CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_API_TOKEN и явном подтверждении Workers Free. Иначе применяется явно настроенный AnyModel image-маршрут, для которого сервер проверяет бесплатность. Автоматического платного fallback нет. Условия тарифов могут изменяться: проверяйте их самостоятельно.

Изображение ИИ не является фотографией фактически приготовленного блюда. Сравните состав и вид перед сохранением. Для старого рецепта без image_prompt создайте новый подбор. Отсутствие подтверждённого маршрута показывается как недоступность, не бесконечная генерация.
