# Черновик политики конфиденциальности «Олива»

НЕ ГОТОВ ДЛЯ ПУБЛИЧНОГО ЗАПУСКА. Перед публикацией указать владельца/контакт, хостинг, применимое право, страны обработки и проверить действующие условия AnyModel и поставщика модели.

1. Приложение обрабатывает выбранные пользователем фотографии продуктов и необязательное фото чека для распознавания, составления рецепта и оценки стоимости.
2. Перед отправкой фото сжимается на устройстве. С согласия пользователя фото проходит через наш сервер в AnyModel и далее поставщику выбранной модели. Не загружайте документы, лица людей, банковские реквизиты и другие лишние данные; закройте персональные сведения в чеке.
3. Код нашего сервера не сохраняет фото/рецепты в базе и не записывает их в журнал. Переданные данные могут обрабатываться/храниться посредником, поставщиком и инфраструктурой по их правилам. Сроки и условия нужно проверить и вписать перед публичным запуском; «полное отсутствие хранения» не обещается.
4. Выбранные фотографии находятся в памяти страницы. При сохранении рецепта в браузере сохраняются рецепт, дата, число порций, регион/валюта и маленькая миниатюра фото продуктов. Фото чека в локальную историю не сохраняется. Между устройствами данные не синхронизируются.
5. Пользователь может удалить отдельные записи или всю историю. Настройки хранятся локально. Хостинг может обрабатывать IP и технические метаданные соединения; короткоживущий счётчик попыток входа использует хеш сетевого адреса, дневные квоты не содержат фото или идентификаторов покупателей из чека.
6. Cookie используется для входа владельца, не для рекламы. Код приложения не содержит рекламной аналитики и не запрашивает геолокацию. Регион для цен вводится вручную.
7. Модель может ошибаться. Рецепт, распознанные данные чека, вес и цены требуют проверки. Оценки без чека не являются актуальными предложениями магазинов. По фото нельзя гарантировать свежесть, аллергенный состав или безопасность пищи.
