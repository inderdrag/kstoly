## Ограничения

Локальная веб-библиотека содержит две фотографии. Совпадение консервативное: зелёная паста с томатами или холодный овощной салат. Для неподходящего блюда показывается отсутствие фото. Библиотека не распространяется отдельно как фотосток.

Для создания фото ИИ есть отдельная кнопка и согласие; результат проверяется перед сохранением. Условия поставщика и квоты описаны в IMAGE-GENERATION.md. Иконка приложения предоставлена владельцем проекта: перед публичным выпуском владелец должен подтвердить права на её использование.
