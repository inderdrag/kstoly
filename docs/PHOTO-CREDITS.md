# Фото блюд — источники и правила

Изображения включены в локальную библиотеку. Это примеры подачи, а не фотографии результата пользователя и не доказательство наличия продуктов. Автор и лицензия доступны в меню рецепта. Изображения не подбираются через публичный API; сторонние запросы при открытии рецепта отсутствуют.

## Ограничения

Начальная библиотека содержит две фотографии. Автоматическое совпадение консервативное: зелёная паста с томатами либо холодный овощной салат. Для супов, мяса, рыбы, десертов и других неподходящих блюд показывается текстовая заглушка. Иллюстрация не определяет состав рецепта. Платной генерации нет; ключ и модель генерации не настроены.

Не заменять локальные фото произвольными URL из ответа ИИ. Для добавления фото проверить оригинал, лицензию, автора и соответствие блюду. Библиотеку не распространять как отдельный фотосток. При добавлении стороннего API отдельно соблюдать его условия, а не только лицензию файлов. Изображения главной страницы и учебного макета предоставлены пользователем: права до публичного релиза нужно подтвердить отдельно.
