## Android 0.9.0 — продукты, библиотека и пошаговая готовка

- До четырёх фотографий продуктов в одном подборе. Лента снимков с удалением, выбор нескольких из галереи; чек отдельно. Фото остаются локально до успешного подбора или удаления. Перед отправкой требуется согласие.
- Быстрые пожелания: «Сытное», «До 20 минут», «Без салатов», «Без духовки». Для новых подборов нужен обновлённый сервер Render 0.9.0. Один подбор не превращается в четыре отдельных запроса из-за четырёх фото.
- Категория и сортировка в одной компактной панели: по подбору, времени, количеству ингредиентов, вашей оценке. Фильтры работают локально, не вызывают нейросеть.
- Поиск в сохранённом по названию и ингредиентам; папки «Завтраки», «На ужин», «Любимое» и свои папки. Один рецепт может быть в нескольких папках. До 50 рецептов, без интернета.
- Цены ингредиентов видны отдельно с источником: оценка, чек, ваша цена. Неизвестные цены можно указать вручную: цена упаковки и её количество в граммах, миллилитрах или штуках. Стоимость пересчитывается по количеству и порциям. «+ ?» означает неполную сумму, не нулевую стоимость остальных продуктов. Проверенные актуальные цены магазинов приложение не обещает.
- Новые подборы содержат подробные действия, нагрев, проверки готовности и время ожидания, когда его можно обосновать. Старые сохранённые шаги автоматически не переписываются.
- «Готовить пошагово»: отдельный нативный экран, свайпы вправо/влево, явные кнопки «Назад»/«Далее», плавный сдвиг и затухание с учётом выключенных системных анимаций.
- Таймер берёт время из конкретного шага, запускается только вручную, поддерживает паузу и изменение времени. Окончание открывает следующий шаг один раз, но НЕ запускает следующий таймер. Проверьте готовность продукта, а время варки — по упаковке. Таймер не является гарантией безопасности еды.
- В фоне сохраняется срок таймера; при возвращении приложение учитывает истёкшее время. Надёжные фоновые звуковые уведомления и будильник при закрытом процессе НЕ реализованы. После перезагрузки телефона таймер восстанавливается на паузе.
- На финальном экране — «Вы приготовили блюдо!» и оценка 1–5, которая сохраняется локально вместе с рецептом.
- Фото: «Сгенерировать фото» → «Создаётся…» → «Посмотреть результат» → «Фото сохранено». Готовый результат сохраняется приватно до решения пользователя. Закрытие предпросмотра не запускает новую попытку и не удаляет результат. При задержке продолжается прежнее задание с тем же requestId/id; платного автоматического повтора нет. Результат у поставщика может истечь, если телефон его ещё не получил; новое фото само не создаётся.
- Сессия и история предыдущих версий сохраняются. Устанавливайте поверх PREVIEW-приложения с той же подписью, не удаляйте приложение и не очищайте данные. Идентификаторы приложения и ключ кеша подписи не менялись. При несовместимой подписи остановитесь, не удаляйте историю ради установки.
- Автоматические проверки: 24 Android unit/UI tests, lint, сборка APK; 57 Node-проверок новых полей, HTTP, совместимости и защиты генерации без платных вызовов. Окончательная проверка камеры, системных отступов, клавиатуры и таймера на физическом телефоне ещё нужна. Windows остаётся 0.7.0; новые нативные экраны относятся к Android.

## Android 0.8.0 — оливковый минимализм

- Новый нативный интерфейс выбранного варианта №1: оливковые акценты, карточки, удобные кнопки, закреплённая навигация. Адаптация под весь экран с безопасными системными отступами и прокруткой длинных рецептов.
- Видимая кнопка «Сгенерировать фото» в каждом рецепте. Если функция выключена, кнопка предложит включить её. Запрос — только после отдельного подтверждения, сохранение — после просмотра. Тариф и квоты сервера продолжают действовать.
- Приблизительные ккал на порцию в подборе и рецепте. Оценка по ингредиентам поступает вместе с новым подбором после обновления сервера Render. Старые рецепты без оценки не получают выдуманный ноль. Изменение числа порций меняет количества ингредиентов, не размер одной порции.
- Запоминание входа из 0.7.1 сохранено. История остаётся на устройстве при обновлении поверх старой версии. Не удаляйте приложение и не очищайте данные.
- 13 автоматических Android-тестов, 24 Node-теста, lint и локальная сборка APK. Проверка на физическом телефоне ещё нужна. Windows не менялся (0.7.0).

## Android 0.7.1 — сохранение входа

- Вход по паролю появляется при первом открытии приложения, а не при подборе блюда.
- Исправлена передача cookie: успешный вход подтверждается сервером и не теряется при следующем запросе.
- Сохраняется только зашифрованная сессия, не пароль. После перезапуска пароль не нужен, пока сессия действительна (до 7 дней, до выхода или изменения настроек сессии сервера).
- Установите APK поверх прежней PREVIEW-версии, не удаляя приложение и его данные. При несовместимой подписи остановитесь, чтобы не потерять историю.
- Пройдены 9 автоматических тестов, lint и локальная сборка APK. Проверка на реальном телефоне ещё нужна. Windows остаётся 0.7.0.

## К столу · первая устанавливаемая версия

- **Windows x64:** Electron/NSIS. Интерфейс с существующего HTTPS-сервера Render. Первый запуск требует интернета. EXE пока без сертификата издателя: Windows может предупредить или заблокировать по политике устройства. Проверяйте источник и SHA256SUMS.txt, не отключайте защиту.
- **Android 8+:** собственные нативные экраны, камера/галерея, выбор блюд, локальная история, стоимость и просмотр фото перед сохранением. Первая версия для проверки, не магазинный выпуск. История сайта и Windows автоматически не переносится.
- Вход — отдельный пароль приложения. Секретные API-ключи находятся только на сервере. Подбор и генерация используют текущие тарифы и квоты сервера.
- **PREVIEW** в имени APK означает тестовую debug-подпись и отдельный package ID. Ключ хранится в кеше Actions; при очистке кеша подпись может смениться, обновление поверх старой версии станет невозможным. Не храните здесь единственную копию важных данных. Для постоянных обновлений нужен release-ключ в GitHub Secrets.
- Android-приложение ещё нужно проверить на реальном телефоне, Windows — на Windows-компьютере. Работа установщика не равна проверке всех функций.
