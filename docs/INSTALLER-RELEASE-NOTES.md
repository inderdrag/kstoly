## К столу · первая устанавливаемая версия

- **Windows x64:** Electron/NSIS. Интерфейс с существующего HTTPS-сервера Render. Первый запуск требует интернета. EXE пока без сертификата издателя: Windows может предупредить или заблокировать по политике устройства. Проверяйте источник и SHA256SUMS.txt, не отключайте защиту.
- **Android 8+:** собственные нативные экраны, камера/галерея, выбор блюд, локальная история, стоимость и просмотр фото перед сохранением. Первая версия для проверки, не магазинный выпуск. История сайта и Windows автоматически не переносится.
- Вход — отдельный пароль приложения. Секретные API-ключи находятся только на сервере. Подбор и генерация используют текущие тарифы и квоты сервера.
- **PREVIEW** в имени APK означает тестовую debug-подпись и отдельный package ID. Ключ хранится в кеше Actions; при очистке кеша подпись может смениться, обновление поверх старой версии станет невозможным. Не храните здесь единственную копию важных данных. Для постоянных обновлений нужен release-ключ в GitHub Secrets.
- Android-приложение ещё нужно проверить на реальном телефоне, Windows — на Windows-компьютере. Работа установщика не равна проверке всех функций.
