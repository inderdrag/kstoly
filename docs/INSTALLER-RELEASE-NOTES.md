# К столу — Android 1.0.1

Кандидат на проверку. Открытая главная без входа; автоматические ориентировочные цены без ручного ввода; ккал на 100 г готового блюда; шаги и таймеры в листаемой карточке прямо внутри рецепта; обновлённый оливковый интерфейс.

Сохранены четыре фото, пожелания, поиск и папки Android-библиотеки, оценки, подтверждение сохранения сгенерированного фото. Старые рецепты без массы готового блюда не получают выдуманную оценку на 100 г.

PREVIEW подписан тестовым ключом. Обновляйте поверх прежней версии с той же подписью, не удаляя данные. Библиотека хранится только на устройстве. Интернет нужен для нового подбора и генерации.

Цены, калории, рецепты и изображения приблизительные. Таймер не гарантирует готовность еды и звук при закрытом приложении. Перед публикацией проверьте на реальном телефоне и настройте устойчивые квоты и бюджет API.

### Новое в 1.0.1
Фиксированный звуковой сигнал при завершении таймера. Без выбора мелодии и без расходов API. Держите приложение открытым; закрытый экран/фон пока не поддерживаются как надёжный будильник. Громкость и режим «Не беспокоить» задаёт система телефона.
