# К столу — Android 1.1.1

- Исправлено ожидание Gemini: общий бюджет до 5 минут вместо 55 секунд, отдельное серверное задание и проверка готовности короткими запросами.
- Восстановление принятого подбора после потери связи/закрытия приложения без повторной отправки снимков и нового вызова модели. На главной — «Проверить прежний подбор».
- Готовый результат доступен на сервере до 24 часов, последний подбор сохраняется на устройстве. Для сохранности серверного кеша нужен устойчивый диск.
- Убраны повторяющиеся инструкции модели; подробность и разнообразие блюд не урезаны.
- «Су-шеф»: шторка над рецептом с отдельной перепиской для каждого блюда. Контекст включает порции, текущий шаг и таймер. Советы не применяются автоматически.
- Android-будильник: уведомление и фиксированный сигнал при блокировке при выданных разрешениях. Один активный таймер, подтверждение замены, отмена при паузе и ручном переходе.
- «Сейчас понадобится»: ингредиенты текущего шага в новых подборах, с пересчётом на порции. Количество показано для рецепта целиком; распределение между шагами уточняется в инструкции.
- Компактная шапка рецепта, фото открывается отдельно.
- Реальные этапы подбора без фиктивного процента. Распознавание и составление рецептов — один вызов Gemini.

Сохранены автоматические ориентировочные цены без ручного ввода, ккал на 100 г, четыре снимка, пожелания, папки и оценки. Старые рецепты не получают выдуманную разметку шагов: сделайте новый подбор.

Установите PREVIEW поверх прежней версии с той же подписью, не удаляя приложение. Разрешите уведомления и «Будильники и напоминания», затем повторно нажмите запуск таймера. Проверяйте громкость будильника; режим «Не беспокоить» и принудительная остановка могут подавить сигнал. После перезагрузки таймер на паузе. В браузере фоновый будильник не реализован.

Кандидат проверен автотестами и рендерами; реальный телефон и фактический ответ маршрута DeepSeek требуют проверки владельцем. Успешная сборка не является магазинной сертификацией. Ключ API только на сервере; регистрация не нужна. Перед открытой публикацией настройте устойчивые квоты, бюджет и утверждённую политику данных.
