# К столу — Android 1.2.3

## Составление блюд по подтверждённому списку

- Второй этап использует отдельную текстовую инструкцию, без протокола ошибок распознавания фотографий. На входе только проверенные продукты, пожелания, техника и структурированные цены чека.
- Кнопка подтверждения: «Всё верно — составить блюда». При обработке — «Составляем блюда…».
- Ответы not_food/bad_photo недопустимы для текстового этапа. Проверка использует существующий предел: максимум два обращения за этап с одним исправлением ответа, без повторной отправки фото. Реальные вопросы безопасности не заменяются выдуманными рецептами.
- При ошибке или необходимости уточнения список остаётся на экране и доступен для правки/повторной попытки. Отдельное распознавание заново не запускается.
- Сохранены подробные рецепты, ограничения техники, режим своих продуктов, ккал/100 г, цены, таймеры и Су-шеф.


## Исправление запуска подбора

- Сохранённый результат распознавания больше не перехватывает явное нажатие составления блюд. Подтверждённый список остаётся на устройстве.
- Кнопка сразу меняется на «Составляем блюда…» и блокирует повторное нажатие до завершения.
- Ход запроса и ошибка показаны непосредственно под кнопкой, даже если верх длинного списка продуктов за пределами экрана.
- После завершившейся ошибки кнопка снова доступна; следующее явное нажатие создаёт новый ID текстового подбора без фотографий.
- Существующий незавершённый запрос проверяется через GET, готовый рецепт открывается без новой оплаты. Автоповторы не добавлены.

## Сохранённые возможности 1.2.0

- Су-шеф: три компактные контурные подсказки в один ряд, без тяжёлых заливок. Подписи отправителя отделены от сообщения.
- Распознавание → редактируемый список продуктов → составление блюд. Исправление, добавление и удаление — локально, без повторной отправки фотографий. После подтверждения списка идёт отдельный текстовый запрос к Gemini.
- «Только из моих продуктов»: без обязательных покупок, с явными допущениями для воды, соли, растительного масла и перца.
- «Есть X из Y ингредиентов»: наличие/недостающее раскрываются по нажатию, базовые продукты отдельно. Количество запасов и свежесть не проверены.
- Сложность рецепта и причины; старым рецептам новые сведения не выдумываются.
- Техника в настройках сохраняется на устройстве: плита, духовка, микроволновка, мультиварка, аэрогриль, чайник. По умолчанию плита/чайник — проверьте список. Пустой набор означает без нагрева.
- При открытой карточке незавершённого приготовления экран Android не гаснет; при завершении, сворачивании и уходе режим отключается автоматически.
- Частичная стоимость подписана понятно и раскрывает учтённые продукты, без ручного ввода цен.

Сохранены свайп закрытия чата, адаптация к клавиатуре, отсутствие обязательных галочек передачи данных и повторного окна обычного подбора. Защитные подтверждения удаления, платной генерации и неопределённого повтора остаются.

Новый подбор теперь обычно требует два обращения: распознавание и составление. Каждый этап считается в общем дневном лимите; редактирование списка не обращается к модели. Подробность рецептов, до четырёх фото Android, ккал/100 г, ориентировочные цены, папки и будильник сохранены. Старые сохранённые блюда не переписываются.

Для полного исправления нужны APK 1.2.3 и сервер 1.2.3. Обновление только сервера не меняет кнопку в установленной APK. Запустите Actions → Build Android — К столу → Run workflow на main. Установите PREVIEW поверх прежней версии с той же подписью, не удаляя приложение. Не очищайте кеш подписания.

Исправление проверено локальными автотестами, Android lint и сборкой без платных запросов. Реальные модели, клавиатура, незатухание экрана и звук на физическом телефоне требуют проверки владельцем. Успешная сборка не является магазинной сертификацией. Ключи только на сервере; регистрация не нужна. Для открытой публикации нужны бюджет, постоянная подпись, устойчивый диск и утверждённая политика данных.
