# Установка Android

Сборка только APK. Откройте Actions → Build Android — К столу → Run workflow. По умолчанию создаётся preview APK и черновик выпуска. Успешный workflow не означает, что все функции проверены на телефоне.

Preview сохраняет package ID `ru.kstolu.app.preview` и ключ кеша `k-stolu-preview-signing-v1`. Не очищайте этот кеш: смена ключа мешает обновлению поверх старой установки. Если подпись не совпала, не удаляйте приложение ради установки без резервной копии истории.

Для постоянной подписи задайте Secrets `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`, включите android_release. Это реквизиты криптографической подписи, не вход пользователя в приложение. Release имеет ID `ru.kstolu.app` и не заменяет preview автоматически. Ключ не входит в APK и удаляется из временной папки сборки.

Проверяйте SHA256SUMS.txt и источник APK. Не отключайте защиту устройства. До широкой публикации пройдите чек-лист README.

При следующей успешной сборке с publish_draft старые установщики снятой платформы удаляются из Assets предыдущих выпусков. Старые APK, теги и история коммитов сохраняются. До выполнения этой сборки прежние Assets могут оставаться доступными.

## Обновление 1.1.1
В Assets нового черновика ищите `K-Stolu-1.1.1-Android-PREVIEW.apk`. Старая уже выполненная сборка не включает новые исходники: запустите workflow заново на main после обновления.

Для фонового звука Android выдайте уведомления и доступ «Будильники и напоминания», затем снова нажмите запуск таймера. «Только в приложении» — режим без системного будильника. Одновременно поддержан один системный таймер. Перезагрузка ставит таймер на паузу; принудительная остановка и системные запреты могут не дать сигналу прозвучать.

Су-шеф использует серверный ключ AnyModel. Дополнительный ключ в APK или пароль не нужны. Для ингредиентов текущего шага создайте новый подбор: старые сохранённые рецепты не переписываются.

Для исправления долгого подбора нужны сервер и APK 1.1.1. Старый уже завершённый запрос с ошибкой 55 секунд восстановить этим обновлением нельзя: у него ещё не было сохраняемого задания. Новые принятые подборы проверяются кнопкой на главной, без новой отправки фото. После потери связи не убирайте код задания, если хотите получить прежний результат.
