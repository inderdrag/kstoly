# К столу

**Вкусно из того, что есть.** Сфотографируйте продукты — выберите блюдо — готовьте по понятным шагам.

[Открыть приложение](https://oliva-photo-helper.onrender.com) · [Скачать APK](../../releases) · [Сборка Android](../../actions/workflows/build-installers.yml)

## О приложении

«К столу» помогает найти применение продуктам из холодильника. Спокойный оливковый интерфейс, крупные действия и рецепт без лишних переходов.

- **До четырёх фотографий** полок, морозилки или продуктов на столе. Чек добавляется отдельно.
- **Разнообразный подбор:** ориентир 6–10 блюд при достаточном количестве продуктов, не только салаты. При скромном наборе вариантов может быть меньше.
- **Быстрые пожелания:** сытное, до 20 минут, без салатов, без духовки.
- **Автоматические примерные цены** ингредиентов и блюда. Никаких форм ручного ввода.
- **Ккал на 100 г готового блюда**, с учётом приблизительной массы после приготовления.
- **Приготовление внутри рецепта:** листаемая карточка, подробные инструкции, таймер этапа, оценка результата. Без списка галочек и отдельного экрана приготовления.
- **Фото блюда по нажатию:** сначала генерация, затем просмотр и решение о сохранении. Повторное получение результата не должно создавать новую генерацию.
- **Android-библиотека:** до 50 сохранённых рецептов офлайн, поиск, папки, оценки. Данные хранятся на устройстве.
- **Без регистрации и входа:** приложение сразу открывает главную страницу. API-ключи остаются на сервере.

## Как пользоваться

1. Добавьте от одной до четырёх фотографий продуктов. По желанию — чек.
2. Выберите пожелания и нажмите **«Подобрать блюда»**. Подтвердите отправку снимков.
3. Откройте блюдо: изучите ингредиенты, примерную стоимость и ккал на 100 г.
4. В блоке **«Готовим по шагам»** листайте карточку. Таймер запускается вручную, а после окончания показывает следующий шаг. Проверяйте готовность еды самостоятельно.
5. Сохраните рецепт. Если нужно фото — нажмите **«Сгенерировать фото»** и проверьте результат перед сохранением.

## Установка Android

APK доступен в [Releases](../../releases). **PREVIEW** — тестовая подпись, не магазинный выпуск. Устанавливайте обновление поверх прежней сборки с той же подписью: не удаляйте приложение и не очищайте данные, иначе локальная история пропадёт.

Для сборки: **Actions → Build Android — К столу → Run workflow**. Для проверки оставьте постоянный release-ключ выключенным. После успешной сборки APK и `SHA256SUMS.txt` появятся в черновике выпуска. Подробнее: [установка и подпись](docs/INSTALLERS.md).

## Что означают цены и ккал

Цены — **ориентиры**, а не проверенный прайс магазина: модель оценивает диапазон по региону и валюте; при читаемом чеке может использовать его данные. Для распространённых продуктов в RUB предусмотрены широкие справочные диапазоны. Неизвестные позиции не считаются бесплатными: итог помечается как неполный. Ручных цен нет.

Калорийность: `энергия всего рецепта / масса готового блюда × 100`. И энергия, и выход блюда приблизительные. При изменении числа порций ккал на 100 г не меняются. Старые рецепты с оценкой только на порцию не переименовываются: создайте новый подбор.

ИИ может ошибаться в распознавании, рецепте и картинке. Проверяйте аллергены, состояние продуктов и безопасное приготовление. Приложение не определяет свежесть и не даёт медицинских рекомендаций.

## Запуск сервера

Требуется **Node.js 24**, дополнительных npm-зависимостей нет.

```sh
cp .env.example .env
# Задайте ANYMODEL_API_KEY и необходимые параметры только в локальном .env.
npm test
npm start
```

Для production задайте `NODE_ENV=production` и `PUBLIC_ORIGIN` с реальным HTTPS-адресом. Настройки описаны в [.env.example](.env.example), пример развёртывания — [render.yaml](render.yaml).

Сервер: Node HTTP + SQLite. Android: Java, Android SDK 35, JDK 17, Gradle 8.11.1. Веб-приложение: HTML/CSS/JavaScript, service worker и локальное хранилище. Android и браузер не синхронизируют библиотеку автоматически; часть возможностей библиотеки реализована только в Android.

## Перед открытой публикацией

Версия исходников **1.0.0 — кандидат на проверку**, а не заявление о пройденной магазинной сертификации.

- [ ] Проверить APK на реальном устройстве: камера, четыре фото, подбор, сохранение, восстановление, генерация и таймеры.
- [ ] Настроить постоянный ключ подписи и сохранить его резервную копию.
- [ ] Настроить жёсткий бюджет у API-провайдера. Открытый API доступен без входа; Origin не заменяет авторизацию.
- [ ] Обеспечить устойчивое хранение квот: бесплатный Render использует временный диск, поэтому при потере файлов счётчики сбросятся.
- [ ] Утвердить публичную политику конфиденциальности, контакты владельца и условия использования, проверить права на зависимости и материалы.
- [ ] Проверить описание выпуска и опубликовать проверенный APK вручную. Видимость репозитория этим обновлением не меняется.

По умолчанию действуют общие дневные ограничения и кратковременный лимит, но это **не гарантия отсутствия расходов или злоупотреблений**. Render Free после простоя может запускаться около минуты. Таймер не гарантирует звуковой сигнал при закрытом приложении.
